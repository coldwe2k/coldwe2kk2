출제 기준과 사용 방법

제공된 5개 PDF와 요청한 시험 범위를 바탕으로 새로 만든 연습문제입니다. 실제 기출문제나 실제 시험의 문항 수·배점 예측은 아닙니다. 장별 범위의 넓이에 따라 2장 18문항, 3장 24문항, 7장 26문항, 8장 30문항, 9장 28문항으로 구성했습니다.

  • 연습 모드: 답을 입력하고 ‘채점·해설 보기’를 누르세요. 수정하면 이전 채점은 해제됩니다.
  • 모의시험: 현재 필터의 문제에서 무작위 추출하며, 여러 장이 있으면 장별로 번갈아 추출합니다. 시험을 제출한 뒤 정답과 해설을 공개합니다. 시험용 답안은 따로 보관하며 제출 시 해당 문항의 학습 기록을 갱신합니다.
  • 객관식은 정답 1개입니다. 짝 짓기·순서 나열은 모든 칸이 맞아야 1점이며 부분 점수는 없습니다. 미응답을 포함한 제출 범위 전체가 점수의 분모입니다.
  • 용어는 등록된 한글·영문 답안을 허용하고 대소문자·공백·하이픈 차이를 무시합니다. 의미가 같은 모든 표현을 자동 판별하지는 못합니다.
  • 숫자는 지정 단위 기준으로 입력합니다. 예: 80%는 80 또는 80%로 입력하며 0.8은 오답입니다. 소수·분수 입력과 천 단위 쉼표를 허용합니다.
  • 자료의 비선점 배치 모델, 인터럽트 처리 순서, Feedback 예제 규칙은 해당 강의 모델을 기준으로 합니다. 일반 구현과의 차이는 관련 해설에 명시했습니다.
  • 각 해설의 출처 페이지는 PDF 파일의 1부터 시작하는 페이지 번호입니다. 파일이 없어도 이 HTML만으로 문제 풀이와 채점이 가능합니다.
  • 진행 상황은 이 브라우저의 로컬 저장소에 저장되며 외부로 전송되지 않습니다. 파일 위치·브라우저 변경이나 저장소 삭제 시 기록이 이어지지 않을 수 있습니다.
